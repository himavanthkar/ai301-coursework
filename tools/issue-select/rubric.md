# Rubric: is this a good first issue?

## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| Recent commits | "last 5 default-branch commits" in repo facts | At least one commit in the last 90 days | required |
| Maintainer responsive | "maintainer first-response sample" in repo facts | Sample shows at least one response from owner/member/collaborator (or repo is very active with recent merges) | required |
| Bounded scope | Issue body and thread | Issue is not explicitly labeled as umbrella/epic/tracking. Does not ask for implementation of a broad capability across many unrelated areas. Related tasks for one coherent feature are OK | required |
| Not claimed | "linked PRs:" section and comment thread | No open linked PRs AND no "I'll take this" or "working on" comments in last 30 days | required |
| AI-friendly policy | "contribution policy" in repo facts | Repo allows AI-assisted contributions or has no stated policy against AI tools | required |
| Good first issue label | "labels:" field in issue section | Has "good-first-issue" label | preferred |

## Verdict rule

Accept if all required checks pass. Reject if any required check fails. Unclear counts as fail. Preferred checks never change the verdict; they only rank accepted issues against each other.
